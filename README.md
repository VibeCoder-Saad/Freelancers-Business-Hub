A powerful, modern, and beautiful desktop application designed for freelancers to manage their business, projects, and clients with style. Built with **PySide6** and a **Hybrid Web+Native** architecture for stunning UI capabilities.

---

## ✨ Key Features

### 🎨 Stunning UI & UX
*   **Hybrid Architecture**: Blends native Python performance with modern Web (HTML/CSS) aesthetics.
*   **Crystal Clear Theme**: A fully customized "Glassmorphism" design with blur effects, animations, and a premium dark mode.
*   **Responsive Dashboard**: Real-time updates and interactive widgets.

### 🔒 Secure Role-Based Access (RBAC)
*   **Freelancer Mode**: Full access to manage projects, billable hours, and settings.
*   **Client Mode**: Restricted, secure view for clients to monitor *only* their assigned projects and pay invoices.

### 🛠️ Project Management
*   **Project Hub**: Manage projects with a Kanban Board or List View.
*   **Time Tracking**: Built-in start/stop timer with automatic log generation.
*   **Evidence Gallery**: View screenshots and activity logs for proof of work.

### 💬 Operations & Finance
*   **In-App Chat**: discuss project details with clients in real-time directly from the dashboard.
*   **Professional Invoicing**: Generate and **Export PDF Invoices** with a single click.
*   **Expense Tracking**: Keep tabs on business costs.

## 🚀 Installation & Usage

1.  **Clone the Repository**
    ```bash
    git clone https://github.com/VibeCoder-Saad/Freelancers-Business-Hub.git
    cd Freelancers-Business-Hub
    ```

2.  **Install Dependencies**
    ```bash
    pip install -r requirements.txt
    ```

3.  **Run the Application**
    ```bash
    python main.py
    ```

---

## 🛠️ Tech Stack
*   **Language**: Python
*   **GUI Framework**: PySide6 (Qt for Python)
*   **Web Engine**: QtWebEngine + QtWebChannel
*   **Database**: SQLite
*   **PDF Generation**: fpdf2
